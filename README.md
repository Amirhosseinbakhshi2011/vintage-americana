# 🇺🇸 Vintage Americana

سایت با حس و حال کلاسیک آمریکایی.

کاغذ کهنه، رنگ‌های navy و قرمز، تایپوگرافی قوی و حال و هوای Route 66.

**ساخته شده توسط امیرحسین بخشی**

---

## تکنولوژی

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion (احتمالاً)

---

## اجرا

```bash
npm install
npm run dev
```

برو روی [http://localhost:3000](http://localhost:3000)
